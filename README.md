# ARC/FORGE LAB

> Games, experiments & weird things.

A collection of small interactive web experiments built with **HTML, CSS, and vanilla JavaScript**.

The project is inspired by the idea of turning simple concepts into fun, interactive browser experiences.

---

## ✨ Experiments

### 01 — Perfect Circle

Draw a circle with your mouse or finger and receive an accuracy score.

**Concepts used:**
- Canvas API
- Pointer Events
- Coordinate geometry
- Distance calculations
- Mathematical scoring

---

### 02 — Gravity Lab

Create gravity sources and watch hundreds of particles react to them in real time.

**Concepts used:**
- Canvas API
- Particle systems
- Vector mathematics
- Gravity simulation
- `requestAnimationFrame()`
- Real-time animation

---

### 03 — Human Scale

Explore objects ranging from microscopic structures to astronomical scales.

**Concepts used:**
- Logarithmic scaling
- Data visualization
- Interactive navigation
- Dynamic DOM updates
- Keyboard and mouse controls

---

### 04 — Spend It

You have fictional money. Spend it on ridiculous things and see where your money goes.

**Concepts used:**
- JavaScript state management
- Dynamic DOM generation
- Event listeners
- Number formatting
- Interactive UI

---

### 05 — Infinite Combine

Combine discovered elements to create new discoveries.

**Concepts used:**
- JavaScript objects
- Arrays
- Game logic
- Combination algorithms
- State management
- Dynamic UI

---

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript
- Canvas API
- Pointer Events
- Browser APIs

No frameworks or external libraries are required.
